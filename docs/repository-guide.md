# 저장소 운영 안내

## 새 공모전 추가

1. `contests/<연도>-<공모전 식별자>/`를 만듭니다. 같은 공모전의 다른 회차는 회차를 식별자에 붙입니다.
2. README에 공모전명, 작품명, 상태, 마감, 공식 링크를 기록합니다.
3. `docs/`, `script/`, `subtitles/`, `prompts/`, `assets/`, `export/`를 초기화합니다.
4. 루트 README의 프로젝트 목록에 등록합니다.

## 문서와 버전

- 규정은 공식 출처·확인일을 기록하고, 사실·해석·창작 설정을 구분합니다.
- 초안에는 초안 표시를 붙입니다. 변경 이유는 프로젝트 `docs/decisions.md`에 남깁니다.
- 문서는 Git 이력으로 관리하고 실제 에셋은 `S01_keyframe_v001.png`처럼 장면과 버전으로 구분합니다.
- 개인 연락처, 참가신청 개인정보, 계정 키는 저장소에 넣지 않습니다.

## 에셋과 제출

- 대형 영상·음성·편집 프로젝트는 기본적으로 Git에서 제외합니다. 외부 보관 위치와 파일명, 버전은 에셋 목록에 기록합니다. 용량과 보관 정책을 정한 뒤 필요하면 Git LFS를 별도 도입합니다.
- 외부 자료의 라이선스, AI 도구·모델·프롬프트와 생성일을 함께 기록합니다.
- 최종본 파일명과 제출 URL·일시는 각 프로젝트 `export/README.md`에 기록합니다.
- 저장소 전체에 일괄 라이선스를 부여하지 않습니다. 제작물과 외부 자료의 권리는 개별 확인합니다.
