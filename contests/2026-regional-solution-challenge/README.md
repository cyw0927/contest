# 서울 서북권 고령자 폭염보행 체감열 지도·그늘배치

과학기술정보통신부·KISTEP·연구개발지원단협의회 **제1회 지역 현안 해결 솔루션 챌린지** 응모안(개인, 서울특별시). 현재 단계: **제안서 초안 v1 작성 완료, 제출 전 수치 원문 대조 필요**.

- 접수 마감 **2026-10-11(일) 18:00**(일부 보도는 10일로 표기 → 10일 내 제출 목표) · 접수 `ideacontest@kistep.re.kr`
