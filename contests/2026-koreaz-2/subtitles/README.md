# 영어 자막 v1.0

[subtitles_en.srt](subtitles_en.srt)는 90초·18샷 제작 대본의 자연스러운 영어 번역입니다. 시간은 각 샷 시작 +0.4초부터 종료 -0.4초까지이며 **녹음·영상 싱크 검증 전**입니다. 실제 음성에 맞춰 조정해야 합니다.

- 최대 두 줄, 줄당 목표 40자. 속도는 실제 재생에서 검수합니다.
- S02의 I agree는 UI로 표시하고 내레이션하지 않습니다.
- S17/S18에는 자막을 넣지 않고 핵심 문구를 크게 합성합니다.
- 최종 제출본에는 영어 자막을 번인합니다. 별도 SRT도 보관합니다.
