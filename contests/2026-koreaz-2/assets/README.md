# 에셋

```text
characters/          두 주인공 기준 시트
storyboard/          세 비주얼 테스트·후편집 SVG·HTML·타이틀
generated/images/    후속 최종 키프레임 (현재 미제작)
generated/video/     후속 5초 클립 (현재 미제작, Git 제외)
audio/               음성·음악·효과음 (현재 미제작, Git 제외)
fonts/               폰트 안내만, 폰트 파일 없음
references/          권리 확인 자료만
images/, video/      초기 폴더 보존
```

[에셋 명세·실제 결과](asset-manifest.md), [CSV 목록](asset-register.csv), [AI 사용 기록](ai-usage.md). 외부 참고 이미지·불명확한 음원·폰트 바이너리는 추가하지 않는다. 생성 이미지는 최종 채택과 얼굴/손/UI 검수가 별도 필요하다.
