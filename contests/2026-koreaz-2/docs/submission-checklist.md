# 최종 제출 체크리스트

## 공식 조건

- [ ] 제출 직전에 [외교부 공고](https://www.mofa.go.kr/www/brd/m_4075/view.do?seq=369399)와 신청서 최신 조건을 재확인했다.
- [ ] 마감 2026-10-25의 정확한 시각·시간대·업로드 용량 제한을 확인했다.
- [ ] 16:9, 1920×1080, MP4 또는 MOV다.
- [ ] 30fps 이상 권장 조건에 맞춘 출력이다.
- [ ] 한국어 음성에 영어 자막을 실제 표시했다.
- [ ] 생성형 AI를 사용한 부분을 구체적으로 적었다.
- [ ] 미래상과 청년의 실천방안을 모두 담았다.
- [ ] 14세 미만 참가자라면 보호자 동의 조건을 충족했다.

## 제작 검수

- [ ] 두 청년 얼굴·옷·기기와 시대 전환이 일관된다.
- [ ] 같은 결과를 얻은 뒤의 이동·선택 조건 차이가 글자 없이 읽힌다.
- [ ] 개인→학교·병원·기업→공공 인프라 연결이 자연스럽다.
- [ ] 2026 실천에 25초, 이동 도구의 작동에 15초가 배정되어 있다.
- [ ] 특정 나라·기업 비하, 실제 의료 정보, 무단 상표·인물 모사가 없다.
- [ ] UI와 핵심 문구는 정확한 후편집 텍스트다.
- [ ] 자막 싱크·읽기 속도·모바일 시청·음량·검은 프레임·재생을 확인했다.
- [ ] 마지막 두 문장이 충분히 읽힌다.
- [ ] 테스트 이미지·HTML 미리보기를 완성 영상과 구분했다.

## 권리·AI 기록

- [ ] 모든 이미지·영상·음원·음성의 출처와 이용 조건을 확인했다.
- [ ] 폰트 파일을 저장소에 포함하지 않았다. 출력에 사용할 폰트의 이용 조건을 확인했다.
- [ ] 외교부의 수상작 비영리·공익 목적 독점 이용·편집 조건에 맞는 자료만 사용했다.
- [ ] 실제 사용한 도구·모델·단계·날짜·최종 반영 여부를 [AI 기록](../assets/ai-usage.md)에 갱신했다.
- [ ] 최종본 파일명·버전·SHA-256·보관 위치를 기록했다.
