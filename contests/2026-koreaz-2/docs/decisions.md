# 기획 결정 기록

## 2026-10-06 — 초기 구조

- 저장소를 확인한 결과 커밋과 파일이 없는 상태였다. `contests/` 아래 공모전별 디렉터리를 둔다.
- 사용자 요청에 따라 제목은 `2036: TERMS & CONDITIONS`, New Border는 세계관으로 유지한다.
- 접근 유무보다 이용 조건의 차이를 중심에 둔다.
- 개인 UI에서 공공서비스로 확대하는 장면과 청년의 구체적 실천을 포함한다.
- 공식 본문의 심사 항목은 ‘활용도’이며 SNS 반응 평가 여부는 확인되지 않았다.
- 100초 구성·대본·자막·프롬프트는 초기 제작 제안이다. 최종 채택은 미정이다.
- 대형 제작물은 기본 Git 제외, 문서·프롬프트·출처·에셋 목록부터 관리한다.

이후 항목에는 날짜, 변경 내용, 이유, 영향을 받는 문서를 기록합니다.


## 2026-10-06 — 사용자 제작 지침 반영 v1.0

- 사용자 첨부 지침과 실사 영화 톤 선택을 반영했다.
- 100초·9장면을 90초·18샷·5막으로 개편. 기존 버전은 Git 이력에 보존.
- 시점을 2036→2026→2036으로 구성했다.
- 행동 B(이동 도구)를 15초, A(언어·오픈 생태계)와 C(권한을 유지하는 공동개발)를 각 5초 배정했다.
- 단일 학습 카드로 문제·행동·결과를 연결. 실제 의료 데이터나 특정 국가/기업 이름은 쓰지 않는다.
- 기존 underscore 프롬프트 파일명과 submission-rules 정본을 유지했다. 요청 이름과 대응은 production-status에 기록.
- assets 기존 images/video 폴더는 보존하고 characters/storyboard/generated/fonts를 추가했다. 폰트 바이너리는 넣지 않는다.
- 18샷 전체 생성 대신 캐릭터·3가지 핵심 비주얼·타이틀 검증만 먼저 수행한다.
