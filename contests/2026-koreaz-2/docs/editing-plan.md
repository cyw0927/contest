# 후편집 계획 v1.0

## 프로젝트와 타임라인

무료 편집 도구의 기본 기능(컷·마스크·원근 변형·텍스트·오디오 키프레임)으로 가능한 구성. [DaVinci Resolve 무료판](https://www.blackmagicdesign.com/products/davinciresolve) 또는 [Shotcut](https://www.shotcut.org/)을 후보로 둔다(공식 사이트 확인 2026-10-06). 프로그램 설치·계정 연결은 아직 하지 않았다. 구체적 지원·출력 옵션은 실제 선택 시 공식 문서로 확인한다.

- 프로젝트: 1920×1080, 가로 16:9, 30fps 고정, 90초/2700프레임.
- S01–S18: 각 150프레임. [샷리스트](../script/shotlist.md)·[timeline.json](../production/timeline.json) 기준.
- V1 배경 플레이트, V2 split screen 인물, V3 UI/경계/학습 카드, V4 연도·명제·질문·제목, V5 영어 자막.
- A1 내레이션, A2 음악, A3 클릭·전송·방 소리. 음성은 다른 트랙보다 명확하게 들리게 조절.

## 컷과 전환

| 구간 | 편집 |

| 50초 | 알림음 멈춤·하드컷·2026 연도 카드. 디졸브/회상 필터 없음 |
| 50–65초 | 내보내기→연결부→다른 시스템에서 작업 이어감. 핵심 행동 15초 |

## UI 후편집

화면 글자는 생성하지 않는다. `assets/storyboard/ui-components.svg`의 카드·열린 문·닫힌 문·아이콘을 투명 오버레이로 사용하거나 편집 도구에서 같은 형태를 재현한다. 정면 화면은 위치/크기 키프레임만, 비스듬한 화면은 4점 원근 합성. 추적 실패 시 정면 인서트로 바꾼다.

T02 테스트는 소리·글자 없이 **양쪽에 결과물이 있음 → 한쪽은 통과 → 다른 쪽은 경계에 남음**이 읽혀야 한다. 색만으로 차이를 표현하지 않는다. 엔딩에서는 선택 통로가 열리지만 민감 자료 잠금은 유지한다.

## 제목·자막

- `Same intelligence. Different terms.`: S17, 80–85초.
- `Who writes the terms?`: S18, 85–90초.
- `2036: TERMS & CONDITIONS`: S18, 88–90초, 작게. 다른 슬로건 없음.
- 자막: 설치된 산세리프 46–50px, 오프화이트, 어두운 반투명 배경 또는 얇은 외곽선, 최대 2줄. 좌우 120px·하단 120px 안전 영역.
- UI 알림은 자막보다 위에 두고 긴 영어 약관을 띄우지 않는다.

## 음악·음량

내레이션 트랙은 피크 약 -6dBFS부터 조정. 음성 구간에서 음악을 음성보다 약 14–18dB 낮게 시작하고 귀로 확인. 최종 통합 loudness 목표 -16 LUFS 안팎, true peak -1dBTP 이하(자체 제작 목표, 공모전 의무 아님). 클릭 소리가 단어를 가리지 않게 한다. [오디오 계획](audio-plan.md)의 감정 곡선에 맞춘다.

## 출력·검수

MP4/H.264, 1920×1080, 30fps, Rec.709, 비트레이트 초기 목표 15–20Mbps, AAC 48kHz/320kbps 스테레오. 신청서 용량 제한 확인 후 비트레이트 조정. 고품질 마스터와 제출본 구분. PNG 테스트 이미지가 FHD보다 작거나 크면 과한 확대 없이 원본 비율을 유지하고 필요한 키프레임을 다시 생성한다.

완성 파일은 `export/koreaz2036_submission_v001.mp4`, 별도 자막은 `subtitles/subtitles_en.srt`. 출력본은 Git 제외. 프레임 수·길이·자막 싱크·재생·음량·크레딧/AI 내역을 최종 검수한다. 90초 HTML 미리보기나 정지 이미지 테스트를 최종 영상으로 제출하지 않는다.
