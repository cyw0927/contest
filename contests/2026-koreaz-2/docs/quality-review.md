## 발견한 위험과 수정

- 초기 100초·9장면은 클립 길이와 맞지 않았다 → 90초·18샷, 각 5초로 조정.
- 언어·이동·주권을 동시에 문제 장면에 나열하면 복잡했다 → 문제는 하나의 카드 이동, 해결에서 언어·공동개발을 압축.
- 두 인물이 의사·교사·정부 담당자로 변하면 현실성이 깨진다 → 각 시설의 이용자·지역 프로젝트 참여자로 유지.
- ‘같은 지능’이 같은 모델 성능의 통계처럼 들릴 수 있다 → 완성된 동일 카드로 극중 상황을 제시하고 리서치에서 비유임을 명시.
- 2026에 2036 프롬프트를 반복하면 시점이 충돌한다 → 현재 도구·더 어린 동일인·연도 카드로 구분.
- 선언문·낙관적 음악으로 해결을 감출 수 있다 → 내보내기·연결·재개 15초를 실제 행동으로 설계.

## 실제 비주얼 테스트 반영

캐릭터·T01/T02/T03·타이틀을 생성/렌더한 뒤 직접 확인했다. T01은 노트북 뒷면이므로 UI 장면으로 사용하지 않고 정면 인서트를 연결한다. T02는 빈 화면에 동일 카드·열린/닫힌 경계를 후편집했고 5초 동작과 끝 상태를 별도 보관한다. T03 v1의 병원 식별 약점은 v2에서 보강했다. 공공 모니터 역방향 인서트와 기업 장면은 최종 샷 제작 때 추가한다. 상세 한계는 [에셋 명세](../assets/asset-manifest.md)에 있다.

## 형식·브라우저 검증

- 18샷 연속 타임라인 90초, 5막, 2026 행동 25초, 이동 도구 시퀀스 15초 확인.
- 15개 영어 SRT 큐가 내레이션과 일치하고 샷 구간 안에 정렬됨. 최대 2줄·줄당 40자·최대 약 12.6자/초. 녹음 싱크 검수는 별도.
- 문서 상대 링크·샷별 이미지/영상 프롬프트·실제 에셋 경로·SVG 구문·폰트 바이너리 미포함 확인.
- 로컬 브라우저에서 T02 5초 모션·끝 상태 버튼, T03 v2 표시, 명제→질문→작은 제목 순서를 확인. 브라우저 오류/경고 로그 없음.
- 일반 관객 이해·최종 영상 재생·음성·권리·신청서 추가 조건은 아직 검수 전.
