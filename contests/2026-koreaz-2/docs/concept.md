# 콘셉트

## 확정된 중심

- 제목: **2036: TERMS & CONDITIONS**
- 세계관: **New Border**
- 명제: **Same intelligence. Different terms.**
- 마지막 질문: **Who writes the terms?**

AI가 일상화된 2036년, 비슷한 도구를 사용하는 두 청년의 선택권이 언어 지원, 데이터 통제, 시스템 이동 가능성에 따라 달라진다. 이 조건은 개인의 화면에서 학교·병원·공공기관으로 확장된다. 청년들은 다국어 자원, 이동 가능한 작업물, 공동개발을 통해 조건을 바꾸기 시작한다.

이 미래는 창작 시나리오입니다. 특정 국가·기업의 현재 상황이나 2036년의 확정 예측으로 제시하지 않습니다. ‘같은 지능’은 동일 성능이라는 실증 주장이 아니라 도구가 보편화되어도 조건은 다를 수 있다는 작품의 명제입니다.

## 서사 초안

1. 두 청년이 같은 모양의 동의 버튼을 누른다.
2. 한쪽의 작업은 이어지고 다른 쪽은 언어·이동 제한에 막힌다.
3. 같은 팝업이 학교·병원·공공기관에도 나타난다. 개인 선택이 사회 인프라의 선택권으로 확장된다.
4. 청년들은 지역 언어 자원을 공유하고, 작업물을 다른 시스템으로 옮기며, 여러 지역 연구자와 공동개발한다.
5. 두 화면의 경계가 연결로 바뀐다. 마지막 질문을 남긴다.

## 연출 원칙

- ‘AI를 가진 사람과 못 가진 사람’보다 **모두 쓰지만 조건이 다른 상황**을 보여준다.
- 두 청년의 의상·공간 수준은 비슷하게 유지한다. 부유·빈곤의 단순 대비를 피한다.
- 국가 차원은 국기 나열보다 공공서비스의 계약 검토·시스템 선택 장면으로 보여준다.
- 해결 장면에 충분한 시간을 배정한다. 선언문 회의보다 실제 작업과 작동 결과를 보여준다.
- 차분한 현실감과 건조한 아이러니. 긴 UI 문장 대신 아이콘·상태 변화·끊기는 선을 쓴다.
- 영어 자막 외 화면 글자는 핵심 명제·질문·짧은 팝업으로 제한한다. 글자는 편집에서 합성한다.
- 오픈모델이나 이동권 하나로 모든 문제가 해결된다고 단정하지 않는다. 공동 구축과 지속적 조정의 시작을 보여준다.

## 다음 확정 사항

인물·국가 설정, 공공기관 장면의 표현, AI 생성 도구, 음악과 목소리, 최종 길이는 미정입니다. 현재 스토리보드·대본은 제작 검토용 제안입니다.
