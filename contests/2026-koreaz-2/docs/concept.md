# 콘셉트 — 제작안 v1.0

## 한 줄 설명

2036년, 같은 AI 결과를 얻은 두 청년의 작업은 서로 다른 경계에서 멈춘다. 2026년의 두 청년은 그 경계를 넘는 기술과 규칙을 만들기 시작한다.

## 중심과 세계관

- 제목: **2036: TERMS & CONDITIONS**
- 세계관: **The New Border**
- 핵심 명제: **Same intelligence. Different terms.** / 같은 지능. 다른 조건.
- 마지막 질문: **Who writes the terms?** / 그 조건은 누가 정하는가?

AI가 널리 쓰이는 2036년을 가정한다. 이 작품의 경계는 AI의 소유 유무보다, 시스템을 선택하고 자기 작업을 가져갈 수 있는 조건에 있다. 모든 사람이 같은 모델을 쓴다는 실증 주장이 아니라, 비슷한 결과 뒤에도 서로 다른 선택권이 있을 수 있다는 허구의 미래 시나리오다.

## 두 주인공과 시각적 반복

A와 B는 2026년 22세, 2036년 32세인 가상의 청년이다. 국적을 지정하지 않는다. 비슷한 공간·기기·생활 수준을 유지한다. A가 우월한 사람, B가 무능한 사람으로 읽히지 않게 **같은 학습 카드가 양쪽에 완성된 뒤** 이동만 달라지는 모습을 보여준다. 캐릭터 고정 규칙은 [캐릭터 바이블](characters.md)에 있다.

산호색 모서리가 있는 학습 카드가 전체 영상의 하나의 작업물이다. 2036년에는 카드가 닫힌 경계에서 멈추고, 2026년에는 카드·작업 기록·설정의 공통 이동 형식을 만들며, 마지막 2036년에는 다른 시스템에서 같은 카드를 이어서 편집한다.

## 개인 → 제도 → 국가

개인 화면의 제한이 학교, 병원 접수, 기업 작업 연계, 공공기관의 대체 서비스 선택으로 반복된다. 공공기관에서는 여러 서비스가 연결된 단순 도식으로 도시·국가 차원의 조달과 협상 문제를 암시한다. 특정 나라의 현실이나 의료 데이터의 무제한 이전을 묘사하지 않는다. 두 주인공은 학교 학습자·병원 이용자·지역 프로젝트 참여자로 등장하고, 장면마다 교사·의사·정부 책임자로 변신하지 않는다.

국가 차원의 질문은 외부 서비스 사용 자체를 부정하는 것이 아니라, 필수 인프라의 운영 조건을 조정하고 다른 시스템을 선택할 여지가 있는가다. 국제 협력과 데이터 통제는 함께 가능하다는 방향을 지킨다.

## 청년의 행동: B → A → C

**B / 떠날 수 있게 만들기 (50–65초, 15초):** 자기 작업 패키지 내보내기 → 공통 형식/연결부 구현 → 다른 시스템에서 같은 카드 이어서 편집. 세 컷이 문제·작업·결과를 모두 보여준다. 기술과 계약상 허용 범위를 함께 설계하는 미래의 실천이며 현재 모든 AI 서비스에 이미 가능한 기능이라는 뜻은 아니다.

**A / 오픈 생태계와 언어 개선 (65–70초):** A가 자기 언어 문장을 녹음하고 B가 오류를 교정해 모델·자료 개선 결과를 공유한다. 실제 청년의 기여 행동을 압축한다.

**C / 고립 없는 데이터 통제와 공동개발 (70–75초):** 서로 다른 지역의 두 사람이 각 지역의 권한을 유지하며 승인된 결과를 연결한다. 외국과 단절하거나 생데이터를 전부 복사하는 방식으로 표현하지 않는다.

AI 리터러시(D)는 별도의 네 번째 해법으로 나열하지 않는다. 조건을 읽고 선택하는 행동에 포함한다.

## 엔딩

모든 문제가 해결된 세계를 만들지 않는다. 개인정보 잠금은 남고, 이용 가능한 다른 통로가 하나 생긴다. S17에서 핵심 명제를 5초 읽히고 S18에서 마지막 질문을 5초 읽힌다. 제목은 끝 2초 작게 등장한다. 새 희망 슬로건을 추가하지 않는다.

## 다른 AI 영상과의 차이

화려한 미래 도시 대신 지금과 닮은 책상과 공공서비스를 쓴다. 지능의 성능 경쟁 대신 ‘같은 결과를 얻은 뒤 어디로 가져갈 수 있는가’를 화면의 반복으로 보여준다. 선의의 선언보다 직접 만든 연결부와 이어지는 작업을 보여준다. UI는 생성하지 않고 편집에서 만든다.

| 부자/가난·프리미엄/무료 비교 | 제외 | 가격 차이만으로 오독될 수 있음 |

| 서버랙·네온 도시·휴머노이드 | 제외 | 이번 이야기의 일상적 불편함을 희석 |

앞선 아이디어의 상세 원문은 현재 제공된 대화에 없으므로 과거 의도를 추정해 기록하지 않았다. 위 제외 이유는 이번 제작 판단이다.
