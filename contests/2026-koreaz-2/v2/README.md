# 2036: TERMS & CONDITIONS — v2

v1(`../docs`, `../script`)은 보존한다. v2는 v1이 "맛이 없다"는 판단 후 처음부터 다시 쓴 기획이다. 상태: **기획 완료, 제작 전**.

## 한 줄

2036년, 우리는 모두 "동의"를 눌렀다. 같은 결과를 얻은 두 청년의 작업물은 서로 다른 약관 앞에서 갈라진다. 2026년의 청년들은 그 약관을 직접 고쳐 쓰기 시작한다.

## v1의 문제와 v2의 해법

| v1 문제 | v2 해법 |
| --- | --- |
| 제목은 약관인데 화면에 약관이 없음 | "I agree" 클릭이 전 영상의 리듬 모티프. 약관 두루마리와 TERMS HAVE CHANGED 팝업이 핵심 장면 |
| 걸린 것이 없음 | 3년치 작업이 쌓인 카드 더미. 떠나면 사라진다는 손실을 한 컷으로 보여줌 |
| 정지된 스톡사진 느낌, 노트북 앞 얼굴 | 손·소품·화면·도시 중심. 2036 얼굴은 최소화 |
| 국제감 0 | 같은 순간, 한쪽은 새벽 한쪽은 저녁. 2026 장면은 여러 시간대에서 동시에 참여 |
| 18샷 균일 5초, 평평한 감정 곡선 | 1초 몽타주 → 5초 대비 → 가속 → 정적 → 열린 편집 장면 → 마지막 클릭 |
| 선언문형 내레이션 235자 | 내레이션 3문장(약 50자). 나머지는 화면과 소리 |
| 행동이 "노트북 앞 사람들" | 행동 = 약관 문서를 여러 사람이 동시에 편집하는 장면(공동 편집 커서) |

## 핵심 장치 4개

1. **I agree 버튼(산호색)**: 시작·중간·끝에 반복. 마지막 컷은 누르지 않은 버튼과 그 위에 멈춘 커서. 관객이 누르는 사람이 된다.
2. **카드 더미**: 두 청년의 3년치 작업. 하나로 완성된 산호색 모서리 카드가 쌓인 형태.
3. **경계선**: 화면 중앙의 가는 세로선(분할 화면의 경계 = 게이트 = New Border). 카드 더미가 이 선을 통과하거나 못 통과한다.
4. **약관 문서**: 1막에 읽을 수 없는 두루마리로 등장하고, 4막에 청년들이 편집하는 문서로 돌아온다. 같은 문서가 바뀌는 것이 영상의 서사다.

## 룩

- **2036(차가움)**: 잉크 블루 `#1B2430` + 차가운 회색 조명 + 산호색 신호 `#FF6B5B` 하나만 사용.
- **2026(따뜻함)**: 꿀빛 오후 자연광, 어수선한 방, 웃음. 같은 산호색이 따뜻한 환경에서 쓰임.
- 인물은 v1 캐릭터(A 단발 흑발·검정 데님 / B 곱슬·올리브 재킷)를 쓰되 2036은 손·뒷모습·소품 중심, 얼굴은 S13과 S25만.
- 스타일은 실사 시네마 기본에, 화면 속 UI는 100% 후편집(생성 금지). 인물 일관성이 흔들리면 컷을 줄이는 쪽으로 대응한다.
- 폰트: 한글 Pretendard, 영문 Inter(바이너리는 저장소에 넣지 않음).

## 외교·규정 원칙(v1 유지)

- 국가·기업명, 국기, 상표, 실제 서비스 UI 사용 금지. 약관 문구는 모두 가상.
- 의료 장면은 실제 데이터 이전 묘사 없이 "Transfer: not included" 같은 일반 문구만.
- 해결이 모든 문제를 없애지는 않는다. 개인정보 잠금은 마지막에도 남는다.
- 실제 선례(근거 메모): 유럽 GDPR 20조의 데이터 이동권. 영상에는 직접 언급하지 않고 리서치 노트로만 사용(출처 재확인 필요).
- 제출 조건: FHD 16:9 30fps 이상, 영어 자막, 생성형 AI 사용 기록, SNS 게시 + 해시태그, 구글폼. 마감 10/25(공식 공고 재확인).
