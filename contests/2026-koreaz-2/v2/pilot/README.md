# 파일럿 — 후편집 그래픽 릴 (graphics.html)

v2 샷리스트 중 **생성 없이 직접 만드는 컷**을 HTML로 구현한 파일럿. 총 28초 릴.

| 구간(릴 시간) | 샷 | 내용 |
| --- | --- | --- |
| 0–3s | S07 | 약관 두루마리가 가속하며 흘러가 "Accept all"에 닿고 클릭 |
| 3–5s | S08 | 제목 **2036: TERMS & CONDITIONS** 타이핑 |
| 5–10s | S19 | 검은 화면, 커서 깜박임(정적) |
| 10–20s | S24 | 약관 문서를 4개 커서(시간대 표기)가 공동 편집: 읽을 수 없는 조항 → 새 조항 3개 |
| 20–23s | S26 | Same intelligence. Different terms. |
| 23–26s | S27 | Who writes the terms? + 누르지 않은 I agree 버튼과 커서 |
| 26–28s | S28 | 작은 제목 → 검은 화면 → 마지막 클릭(소리 켠 경우) |

## 사용법

- `graphics.html`을 브라우저로 열면 자동 재생된다(Space = 재생/정지, 하단 바로 장면 이동·소리 켜기).
- 녹화용: `graphics.html?clean` (컨트롤 바 숨김). 브라우저를 1920×1080 크기로 맞춘 뒤 OBS 또는 Windows 게임 바(Win+G)로 화면 녹화.
- 특정 시점 확인: `graphics.html?t=18.5` (초 단위, 정지 상태).
- 현재 PC에 ffmpeg가 없어 MP4 자동 렌더는 하지 않았다. 최종본은 편집 프로그램에서 녹화 영상을 가져와 쓴다.

## 상태

- 화면 확인 완료(S07 스크롤·클릭, S08 타이핑, S24 편집 진행·완료, S27 엔딩). 소리(클릭음)는 코드만 있고 청취 검수는 안 함.
- 문구는 모두 가상. 실제 서비스·기업·국가 표기 없음.
- 아직 안 한 것: 영상 클립(P1의 S01–S06 손 접사 등), S18 도시 플레이트(P3), 실제 약관 문구 폰트 정리, 녹화본 렌더.
