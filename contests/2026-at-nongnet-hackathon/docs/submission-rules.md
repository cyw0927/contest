# 제출 규칙 요약

출처: 대회 공식 페이지(https://hackathon.imaginationgroup.co.kr/nongnet)와 주최측 배포 **작성 서식(DOCX)·작성 예시(PDF)**. 확인일 2026-10-16.

## 참가
- 무료, 온라인. 나이·소속·전공 제한 없음, 개발 경험 불필요. 1인팀 또는 2~4인팀, 팀에 **내국인 1명 이상**, 모집 300명 내외, 중복 신청 불가.
- 다인팀: 팀원 각자 회원가입 → 팀장 초대 → 전원 수락·확인 → 팀장이 신청. 예선 마감 전까지 팀 구성 변경 가능.
- **참가 신청과 기술서 제출 모두** 2026-09-07 00:00 ~ **2026-10-18(일) 23:59 KST**. 신청 완료 후 접수번호가 발급된다(신청 완료 화면·접수 확인 메일).

## 예선 제출물 (아이디어 예측 활용안)
- 1개 파일, PDF 또는 DOCX, **A4 10쪽 이내**(표·그림 포함), 별도 표지 불필요. 파일명 `아이디어예측활용안_접수번호.pdf`(또는 .docx).
- 본문 3개 항목의 **제목·순서 유지**: 01 예측아이디어(1-1 예측아이디어, 1-2 도식) / 02 구현을 위한 데이터(2-1 활용 데이터 선택) / 03 예측 활용안(농넷 가격예보 화면 예시 + 화면 설명).
- 운영자 안내·작성 예시·입력 표시는 삭제하고 검정색으로 작성. 본문 11pt 내외 권장. 참가자가 만든 도식·화면 예시는 남긴다.
- **익명 심사:** 접수번호로만 식별. 이름·팀명·소속·연락처를 적지 않고, 파일명·문서 속성(작성자)·메모·변경 기록에도 식별 정보를 남기지 않는다.
- 코드·예측 CSV·완성 모델은 예선에서 제출하지 않는다. **확인하지 않은 성과를 실험 결과처럼 쓰지 않는다**(제안임을 분명히).
- 제출: 참가 신청 후 `/nongnet/submissions`(예선 제출 창구).

## 심사
- 예선(서면): AI 정량평가 50점(Claude·ChatGPT·Gemini 평가 합산 후 환산) + 정성평가 50점 → **본선 15팀**. 공개 기준: 실제 구현·활용 가능성 / 데이터와 아이디어의 연결성 / 활용 대상과 방안의 명확성. 결과는 통과·미통과만 안내.
- 본선: 5개 품목 평균 오차율 순위(공개된 모든 회차 동일 비중), 이후 소스코드 재현 검증(외부 API 없는 폐쇄망 → 외부 데이터는 스냅숏 제출). 우수 모형은 농넷 적용 검토, 산출물 이관·라이선스 공동사용 동의서 제출.
