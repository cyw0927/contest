# 분석과 접근 방향 (초안)

작성 2026-10-16. 사실은 [제출 규칙 요약](submission-rules.md), 해석은 이 문서.

## 이 대회의 성격
- 예선은 **글쓰기 평가**(아이디어·데이터·활용안), 본선은 **실제 시계열 예측 대회**(평균 오차율)다. 예선 통과 후 2주간 5개 품목 모델을 만들어 매 회차 제출해야 한다.
- 예선 서식이 요구하는 3요소: 예측 원리(도식 포함) / 쓸 데이터(농넷 R01~R06 중 선택) / 농넷 가격예보 화면 예시.

## 접근 방향 (예선 기술서)
- **핵심 아이디어:** 예측가격 숫자만이 아니라 “현재 공급 국면”을 읽고 이유까지 보여주는 예보. 기준가격(7거래일 중앙값) 대비 변화율을 예측 대상으로 두고, (가) 최근 가격 유지 (나) 계절 방향 보정 (다) 수급·날씨 보정을 과거 오차 기준 비중으로 합친다. 신호가 약하면 (가)에 가깝게.
- **차별점:** 주최측 예시가 “유사 과거 사례 비교”이므로 겹치지 않도록 방법 혼합·국면 설명·미개선 구간의 기준선 회귀 원칙을 내세웠다.
- **데이터:** R01(필수)·R02(단기 수급)·R04(주산지 날씨)·R05(재배면적·생산량)·R06(수입, 저장 작물)·공휴일 달력. 예보 데이터는 쓰지 않는다(재현성·미래 정보 방지).
- **활용안:** 농넷 가격예보 화면 1개(품목 탭, 실제+예측 그래프, 참고범위, 가격 압력 요인) + 이용자별 쓰임.

## 위험
- 검증을 안 한 아이디어라 **성과를 쓰지 않는다**(규칙). 본선은 별도 역량·시간이 필요하다.
- 같은 시기 다른 마감(KOREAZ 10/25, 제주 활용사례 10/31)과 겹친다.
- 예선 서식의 R01~R06 목록은 참고 번호이며 실제 제공 데이터는 대회 확정 공지를 확인해야 한다.
