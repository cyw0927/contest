# 2026 AI 농산물 가격예측 온라인 해커톤 (농넷)

aT(한국농수산식품유통공사) 주최, (주)상상력집단 주관. 현재 단계: **예선 기술서(아이디어 예측 활용안) 초안 작성 완료, 접수번호 발급·최종 검수 전**.

- 공식 페이지: https://hackathon.imaginationgroup.co.kr/nongnet
- 예선(참가 신청 + 아이디어 기술서) 마감 **2026-10-18(일) 23:59 KST**
- 과제: 배추·무·양파·깐마늘·건고추 5개 품목 도매시장 경락가 예측(10일 일별 + 2순·3순 후)
- 예선 심사: AI 정량평가 50 + 정성평가 50 → 본선 15팀. 본선: 5개 품목 평균 오차율 순위 + 소스코드 재현 검증

## 주의

- public 저장소다. **익명 심사**라서 기술서 본문에 이름·팀명·소속을 넣지 않고, 개인정보와 접수번호가 든 최종 제출본은 올리지 않는다.
- 기술서 초안은 심사 전까지 로컬에서만 관리한다(아이디어 선공개 방지). 제출 후 `export/README.md`에 제출 일시만 기록한다.
- 주최측 서식·예시 파일은 재배포하지 않고 위 공식 페이지에서 받는다.
