# 2026 제주 관광 데이터 활용사례 공모전

제주관광공사 주최 **「2026 제주 관광 데이터 활용사례 공모전」** 응모 프로젝트. 현재 단계: **공고 분석 완료(2026-10-16), 주제·분석 설계 전**. 작품은 아직 없다.

- 공식 공지: [제주관광빅데이터플랫폼 공지사항(2026-09-01)](https://data.ijto.or.kr/bbs/BBSMSTR_000000000080/view.do?nttId=H000000000801Cs2zE7k)
- 접수 마감 **2026-10-31(토) 18:00** · 서류 제출은 [구글 폼](https://forms.gle/PfCtAsbdqjPne36c7) (공지 기준)
- 심사: 1차 서면평가(11월 첫째 주) → 2차 발표평가(11월 셋째~넷째 주)
- 핵심: **“데이터를 실제로 활용해 성과를 낸 사례”** 공모다. 아이디어 공모가 아니다.
