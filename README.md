## 구조

```text
docs/                         통합 저장소 운영 안내
contests/<연도>-<공모전>/
  README.md                   작품 개요와 진행상황
  docs/                       규정·콘셉트·리서치·스토리보드
  script/                     대본·샷리스트
  subtitles/                  자막과 타이밍 기록
  prompts/                    이미지·영상·음성 프롬프트
  assets/                     이미지·영상·음성·참고자료
  export/                     편집본·최종 제출본
```

새 공모전은 독립 디렉터리로 추가하고 이 표에 등록합니다. 공통 운영 기준은 [저장소 안내](docs/repository-guide.md)를 참고하세요. 현재 등록된 마감과 규정은 2026-10-06 확인 기준이며 제출 전 다시 확인합니다.
